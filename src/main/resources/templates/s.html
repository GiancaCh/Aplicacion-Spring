S - Single Responsibility Principle (Principio de Responsabilidad Única)

Este principio establece que cada clase o módulo debe tener una única responsabilidad, es decir, una sola funcion o razón para cambiar.
Al mantener cada clase enfocada en una sola tarea, el código es claro, fácil de mantener y menos propenso a errores
al momento de hacer alguna modificación.
